# РТ-Техприёмка: демонстрационный сайт

Основные страницы перенесены из приложенного handoff в Astro: `/`, `/solutions/etalon`, `/solutions/quality`, `/solutions/supply`, `/career`. Исходные тексты и расчёты скролл-сцен сохранены; общие шапка, подвал и дизайн-токены вынесены в компоненты. `npm ci`, затем `npm run build`; локальный просмотр — `npm run preview`.

Это публичное демо редизайна. Вымышленные клиенты и кейсы, условные характеристики замен, сроки FAQ, адрес офиса, лицензии и неподготовленные разделы требуют проверки. Фото созданы ИИ, у «Техпоставки» остаются визуальные заглушки. Форма проверяет поля, но ничего не отправляет и не показывает ложное подтверждение отправки. Добавлена базовая мобильная адаптация; полноценная проверка мобильных скролл-сцен остаётся задачей перед рабочим запуском. Метаданные и robots.txt запрещают индексацию демо. GitHub Actions собирает и публикует сайт в GitHub Pages при обновлении main.

Страница «Карьера» — согласуемый адаптивный макет: шесть направлений, возможности и поддержка, три демонстрационные вакансии и переход на hh.ru, истории, этапы найма и форма резюме. Контент и конфигурация — `src/data/career.ts`. Форма не отправляет данные без явно подключённого обработчика. Дополнительные льготы, обучение, рейтинг и юридические документы требуют подтверждения. Изображения созданы ИИ и отмечены как демонстрационные. Стили карьерной страницы изолированы от остальных разделов; ссылки «Карьера» добавляются в навигацию при конвертации исходных страниц.
