# РТ-Техприёмка: демонстрационный сайт

Четыре утверждённые страницы перенесены из приложенного handoff в Astro: `/`, `/solutions/etalon`, `/solutions/quality`, `/solutions/supply`. Исходные тексты и расчёты скролл-сцен сохранены; общие шапка, подвал и дизайн-токены вынесены в компоненты. `npm ci`, затем `npm run build`; локальный просмотр — `npm run preview`.

Это публичное демо редизайна. Вымышленные клиенты и кейсы, условные характеристики замен, сроки FAQ, адрес офиса, лицензии и неподготовленные разделы требуют проверки. Фото созданы ИИ, у «Техпоставки» остаются визуальные заглушки. Форма проверяет поля, но ничего не отправляет и не показывает ложное подтверждение отправки. Добавлена базовая мобильная адаптация; полноценная проверка мобильных скролл-сцен остаётся задачей перед рабочим запуском. Метаданные и robots.txt запрещают индексацию демо. GitHub Actions собирает и публикует сайт в GitHub Pages при обновлении main.
