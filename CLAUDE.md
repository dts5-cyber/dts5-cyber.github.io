## Формат .dc.html (как читать исходники)
- Разметка внутри `<x-dc>…</x-dc>`, CSS — в `<helmet><style>`.
- `{{name}}` — значение из `renderVals()`; `<sc-if value="{{flag}}">` — условие; `<sc-for list="{{arr}}" as="x">` — цикл.
- Логика — `<script type="text/x-dc">class Component extends DCLogic { … renderVals() {…} }</script>`: state/setState как в React-классе, `componentDidMount` вешает `scroll`-слушатель.
- `data-props` на скрипте — «твики» (варианты блоков, enum). Брать **default**-значения — это утверждённые варианты. Невыбранные варианты (`<sc-if>` с другими флагами) можно выкинуть.
- Ссылки между страницами: `href="Etalon.dc.html"` → заменить на роуты.

## Стек (рекомендация)

## Ключевые механики (сохранить 1:1)
1. **Scroll-scrub видео**: секция высотой 320–520vh, внутри `position: sticky` экран; прогресс `p = (84 - rect.top) / (rect.height - innerHeight + 84)`; `video.currentTime = f(p)`. Видео перекодированы all-intra/GOP 4 — не пережимать с длинным GOP, иначе скраб дёргается.
2. **Показания на скролле** (Эталон): температура интерполируется по таймкодам сцен (см. `KP` в Etalon), шкала −196…+2500, маркер «Излучатели АЧТ» подсвечивается на финале.
3. **Сцена «О предприятии»**: sticky-фото на всю ширину → сжимается до 50% слева, справа 3 компактные карточки въезжают по очереди (всё в одном закреплённом экране).
4. **Карточки направлений, стопка** (`svcStack`): одна карточка на экран, следующая «наезжает» clip-path снизу.
5. **Сканер замены** (Эталон, импортозамещение): у каждой замены своя SVG-схема датчика, медная линия сканирует слева направо, таблица характеристик проявляется построчно, ↑ — «лучше оригинала».
6. **Kinetic-аргументы**, FAQ-аккордеон, кейсы с переключением, бенто кросс-продаж (цвета по направлениям).
7. `prefers-reduced-motion` — отключать анимации.
