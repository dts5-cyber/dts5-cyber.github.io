Редизайн rttec.ru — пакет для Claude Code

Сводка всего, что сделано в чате с Claude: решения, структура страниц, механики анимаций, ассеты, открытые вопросы и готовый промт для переноса макета в код и деплоя.

Заказчик: АО «РТ-Техприёмка», ГК «Ростех»Обновлено: 2 октября 2026

Важно: это сайт РТ-Техприёмки, не «РТ-Центр инжиниринга» (ЦИ). Брендинг и тексты ЦИ здесь не применять.

1. Как перенести проект в Claude Code

  1. Распакуйте архив в новую папку, например rttec-redesign/. Внутри: этот файл, CLAUDE.md, source/, assets/, content/, previews/.
  2. Откройте папку в Claude Code (терминал: cd rttec-redesign && claude, или в десктоп-приложении → вкладка Code → выбрать папку). CLAUDE.md подхватится автоматически — там сжатый контекст проекта.
  3. Вставьте стартовый промт из раздела 7 этого документа. Claude Code соберёт проект (Astro), перенесёт главную и три страницы направлений, подключит ассеты.
  4. Проверьте локально: npm run dev → откройте в браузере, прокрутите все scroll-сцены. Сверяйте с превью в папке previews/ и с живым макетом.
  5. Git и деплой: попросите Claude Code создать репозиторий на GitHub (gh repo create) и подключить Vercel или Netlify (бесплатно, статикой). Видео ~19 МБ суммарно — для GitHub Pages тоже подходит, Git LFS не нужен.
  6. Продолжайте оставшиеся страницы направлений по шаблону (раздел 6) — в том же репозитории.

3. Как устроены исходники .dc.html

Формат Claude Design: обычный HTML + мини-шаблонизатор + класс логики. Переводится в любой фреймворк почти механически.

  • Разметка — внутри <x-dc>…</x-dc>; глобальный CSS — в <helmet><style>.
  • {{name}} — значение из renderVals() (часто это строка inline-стиля, вычисленная от прогресса скролла).
  • <sc-if value="{{flag}}"> — условный блок; <sc-for list="{{arr}}" as="x"> — цикл.
  • Логика: class Component extends DCLogic — state, setState, componentDidMount (вешает scroll через requestAnimationFrame), renderVals().
  • data-props — «твики» с вариантами блоков. Утверждены значения default; ветки других вариантов можно не переносить.
  • Межстраничные ссылки href="Etalon.dc.html" → роуты сайта.

5. Страницы и решения

Главная (Main.dc.html) — тёмная scroll-сцена

  • Hero: видео со сборкой логотипа из стеклянных кубов (logo_scrub.mp4) перематывается скроллом. Логотип и меню в шапке появляются, когда кубы «приходят» на место.
  • Интро: «Развиваем производство, контролируем качество, обеспечиваем предприятия всем необходимым — для технологического будущего промышленности». Глаголы выделены медным градиентом из цвета hero; слова проявляются при скролле. Капс и подчёркивание отклонены.
  • Три направления: карточки «Развивать / Контролировать / Обеспечивать» — фото на всю карточку, по одной на экран, со ссылками на 9 направлений (Эталон, Сертификация, Снабжение уже ведут на свои страницы).
  • География: три режима (приёмки, регионы, представительства); кнопка «Подобрать решение» под цифрами.
  • «Нам доверяют»: сетка логотипов, клик раскрывает кейс (задача / решение / результат, 2 цифры). Клиенты и цифры — демо.
  • Форма: «Подберём решение под вашу задачу», без шагов и выбора направлений, валидация полей и согласия.
  • Подвал: Техприёмка (История, СМК, Раскрытие информации, Закупки, Кадровая политика, Противодействие коррупции), Решения для бизнеса (9 направлений), Пресс-центр, Карьера, Контакты. Без кнопки заявки.

7. Стартовый промт для Claude Code

Скопируйте целиком в первый запрос в Claude Code, открытом в папке пакета.

Прочитай CLAUDE.md и README-HANDOFF.html — это перенос макета сайта rttec.ru (АО «РТ-Техприёмка») из Claude Design в код.

Задача:
1. Создай проект на Astro (TypeScript, без UI-библиотек) в этой папке: src/pages, src/components, src/styles, public/assets (скопируй assets/ туда).
2. Перенеси 4 страницы из source/dc-local/: Main.dc.html → /, Etalon.dc.html → /solutions/etalon, Quality.dc.html → /solutions/quality, Supply.dc.html → /solutions/supply. Hub-v1, Mega, Mobile — архив, не переносить.
3. Для каждой страницы бери только утверждённые варианты блоков (default в data-props), остальные ветки sc-if выкидывай.
4. Логику renderVals/onScroll перенеси в небольшие клиентские скрипты (vanilla TS) по компонентам: ScrollVideoHero, AboutScene, ServicesStack, ImportScanner, KineticWhy, CasesSwitcher, Faq, ContactForm, CrossSellBento, Header, Footer. Расчёт прогресса скролла и все тайминги сохрани 1:1.
5. Общие токены (цвета, медный градиент .cu, Onest, отступы) — в src/styles/tokens.css. Шапку и подвал сделай общими компонентами.
6. Тексты переноси дословно. Ссылки между страницами — на новые роуты.
7. Добавь prefers-reduced-motion, корректные alt, мета-теги и OG для каждой страницы.
8. Сверь результат с previews/*.png (сделай скриншоты Playwright тех же состояний и покажи различия).
9. Инициализируй git, сделай коммит, затем помоги задеплоить: GitHub-репозиторий + Vercel (или Netlify).

Работай поэтапно: сначала каркас и главная, покажи результат, потом страницы направлений.

8. Хронология и ключевые решения (выжимка чата)

  1. Исследование и структура — Docs-артефакт с анализом, CJM и структурой; светлая концепция v1 (хаб, мега-меню, мобильная) — затем отказ в пользу тёмной «WOW»-сцены v2.
  2. Главная v2 — hero-видео со сборкой логотипа, интро с медными глаголами (подобраны из цвета hero), карточки направлений, география, «Нам доверяют» с кейсами, форма без шагов, подвал с 4 колонками, шапка появляется вместе с логотипом, контурный квадрат-CTA.
  3. Шаблон направления по AIDA на Эталоне: видео датчика → новое видео «от холода к жару» из 6 сцен; «О предприятии» прошло мозаику → сцену по референсу Sibex (фото сжимается, карточки справа) → миссия перенесена в заголовок сцены, карточки сделаны компактными в один экран.
  4. Импортозамещение: табло «было/стало» → таблица/карточки → табло-перевёртыш → выбран «Сканер замены» со схемами и таблицей характеристик (↑ лучше).
  5. Аргументы: 4 варианта → «крупно по одному» с формулировками-действиями → на Эталоне блок убран.
  6. Кейсы, FAQ, кросс-продажи: кейсы в формате главной; FAQ перед формой; кросс-продажи — бенто с вопросами-заголовками, цвета по направлениям, в один экран.
  7. Кволити+ и РТ-Техпоставка собраны по шаблону; у Кволити+ своё видео «печать соответствия».
  8. Предпочтения заказчика: никакого капса; медь — единственный акцент; лаконичные тексты, без «воды»; демо-данные явно помечать; варианты предлагать на выбор, затем фиксировать один.
